🔒 Closure rule (BLD-8.4)
enforcement

An Intercom-origin incident creates a two-way lock:

1. Intercom side · webhook handler stores livera_incident_lock = INC-00347 in conversation metadata. Livera's Intercom app intercepts close attempts and returns 423 Locked with a message pointing the agent to the open incident.

2. Livera side · when the incident transitions to resolved or closed, the save handler clears the metadata flag via Intercom API and (optionally) auto-closes the conversation.

⚠ The lock survives Intercom restarts, agent handover, and conversation reassignment — it lives on the conversation record itself. Workspace admins cannot bypass it.
