Intercom · Webhook configuration
BLD-8.2 sets up the inbound webhook from Intercom to Livera. When a patient message in Intercom is flagged by the AI-classifier as clinical (allergic_symptom, severe_se, safeguarding, etc.), Intercom POSTs to Livera which then auto-creates an incident (BLD-8.3) and locks the conversation (BLD-8.4).

Event subscriptions
Choose which Intercom events trigger the webhook. The handler (BLD-8.3) only creates an incident if the conversation is also flagged by the classifier above the configured threshold — these subscriptions just gate which events Intercom sends us at all.
Classifier thresholds
Webhook handler only creates an incident when classifier confidence ≥ threshold for one of the listed labels. Below threshold → conversation flows normally to support. Configurable per workspace.

Reference · webhook payload shape
Inbound payload from Intercom
For Yohan · this is what BLD-8.3 handler must parse
// POST https://api.livera.health/v1/webhooks/intercom/feeltru
// Headers: X-Hub-Signature-256, X-Intercom-Delivery-Id, Content-Type: application/json
{
  "type": "notification_event",
  "app_id": "app_feeltru_h7k29x",
  "data": {
    "type": "notification_event_data",
    "item": {
      "type": "conversation",
      "id": "IC-29481",
      "created_at": 1745960322,
      "user": {
        "id": "sc_0419",                  // Intercom user_id
        "external_id": "pat_sc_0419",        // Livera patient_id
        "email": "sarah.cookland@example.com"
      },
      "source": {
        "body": "Hi — I had my injection this morning...",
        "delivered_as": "customer_initiated"
      },
      "custom_attributes": {
        "livera_classifier_label": "allergic_symptom",
        "livera_classifier_score": 0.86
      }
    }
  },
  "topic": "conversation.user.created",
  "id": "notif_a8821e34"                  // idempotency key
}
Handler steps (BLD-8.3): verify HMAC signature → check idempotency cache → resolve patient via user.external_id → look up most recent active order → check classifier label is subscribed AND score ≥ threshold → write incident with incident_origin = 'intercom' · intercom_conversation_id = item.id · created_by_system = 'system_intercom_webhook' → call back to Intercom API to set conversation.metadata.livera_incident_lock (BLD-8.4) → trigger prescriber notification → return 200 to Intercom in <500ms.
