Consultation types BLD-CONS-SETTINGS-01

Define what consultation types this clinic offers, the modality and provider for each, default duration, and recording posture · DEC-40 · Foundation for the Schedule + Consultation detail screens
📋
How consultation types work Each type is a template — defines modality (video/phone/chat), provider (Google Meet, Intercom Phone), default duration, who can deliver it (which roles), how patients book it (admin-scheduled vs patient-self-served via Calendly), and recording posture. Patients see only the types you enable. Disabling a type hides it from new bookings but preserves all historical records. Changes audit-logged to AUD-04.

Consultation types · BLD-CONS-SETTINGS-01 · DEC-40 · Each type is a template feeding the unified consultation entity. Modality, provider, duration, recording posture, and identity check requirements are configurable per type per clinic. Types can be enabled/disabled without affecting historical records. Changes audit-logged to AUD-04 · CONFIG_CONSULTATION_TYPE entries. Visible to Owner and RM only — operational roles see consultation types as read-only on the Schedule.
