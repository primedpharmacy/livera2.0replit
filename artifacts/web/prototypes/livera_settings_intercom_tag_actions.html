Intercom tag actions BLD-INT-INTERCOM-02

When an Intercom tag is added to a patient conversation, Livera takes a configured action automatically. 7 active rules · clinic-customisable · changes audit-logged. Tags applied to live conversations route through conversation.user.tag.created webhook.
🏷
How tag actions work Admin tags an Intercom conversation (manually or via Intercom AI classifier) → Intercom fires conversation.user.tag.created webhook → Livera matches tag name against active rules below → executes action(s) on Livera side. Tag→action rules are clinic-configurable like consents and SLA tints — no hardcoded clinical logic. Severe-outcome rules (red triggers below) are protected per DEC-36 and cannot be downgraded by clinic admin without Owner sign-off.
