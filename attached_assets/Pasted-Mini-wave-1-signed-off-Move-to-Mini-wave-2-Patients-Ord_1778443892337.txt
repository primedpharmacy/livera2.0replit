2. lib/format.ts
   Utility formatters:
   - formatDate(iso: string): "DD MMM YYYY" using date-fns
   - formatDateTime(iso: string): "DD MMM YYYY, HH:mm"
   - formatRelativeTime(iso: string): "2 hours ago", "yesterday", etc. using date-fns formatDistanceToNow
   - formatBMI(value: number): "30.9" (1 decimal place)
   - formatWeight(kg: number): "84.2 kg"
   - formatCurrency(amount: number, currency: "GBP"): "£220.00"

3. components/shared/StatusBadge.tsx
   A polymorphic badge for various status types (Patient.status, Order.status, etc.)
   Props: { value: string, kind: "patient" | "order" | "incident" | "complaint" }
   Maps status values to badge variants (ok/warn/err/info) and colour-coded labels.
   Example: order.status="clinical_check" → amber badge "Clinical Check"
   Example: patient.status="active" → green badge "Active"
   Use Lucide icons inside the badge where it adds clarity.

4. components/shared/LoadingState.tsx
   Reusable loading skeleton component. Renders shadcn Skeleton primitives in patterns:

   - LoadingState.List (skeleton item rows for list layouts)

5. components/shared/EmptyState.tsx
