Holiday calendar
UK public holidays (England & Wales) used by the dispatch date calculator. Primed Pharmacy does not dispatch on these dates. Holidays affect the four-scenario dispatch calculation: orders approved on or near a holiday roll forward to the next working day.
ℹ️
Source of truth: The system pre-loads UK Government's official bank holiday list (gov.uk/bank-holidays.json) for England & Wales. Admins can add clinic-specific non-working days (e.g. company shutdown) on top of system holidays. System holidays cannot be deleted — only overridden as "working" if Primed confirms operations.

How the holiday calendar is used
1.
Dispatch date calculator — when an order is approved, the system calculates the next working day for Primed dispatch. Saturdays, Sundays, and dates marked here are skipped. View calculator →
2.
SLA timers — Intervention SLA (7 working days) and GP letter SLA (48h) both pause through holidays. A breach calculated on a Friday before a long weekend won't escalate until the next working Tuesday.
3.
Patient communications — outbound Omnisend templates (dispatch confirmation, "your order is on the way") render the calculated dispatch date to the patient. Patients see "Estimated dispatch: Tuesday 05 May" not "Monday 04 May".
4.
Order expiry timer — the 6-day expiry window (BLD-3.3) is calendar days, not working days, so it's not affected by this calendar. Holidays delay action but not expiry.
Configuration reference
clinic_config.holiday_calendar.region = "england-and-wales"
clinic_config.holiday_calendar.source = "gov.uk/bank-holidays.json"
clinic_config.holiday_calendar.sync_schedule = "weekly" · Mondays 03:00 UTC
clinic_config.holiday_calendar.dispatch_skips = true
clinic_config.holiday_calendar.sla_pauses = true
clinic_config.holiday_calendar.expiry_pauses = false · expiry uses calendar days
